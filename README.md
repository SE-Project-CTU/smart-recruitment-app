# 🚀 Hướng dẫn Cấu hình JWT & Chạy Backend (Sử dụng File `.env`)

## 🛠️ Bước 1: Chuẩn bị Môi trường

- Cài đặt package DotNetEnv ở project ./Backend/src/SmartHire.Api để load file `.env` vào biến môi trường.

```
dotnet add ./Backend/src/SmartHire.Api package DotNetEnv
```

## 🔑 Bước 2: Tạo và Cấu hình File `.env`

Tạo file `.env` trong thư mục ./Backend/src/SmartHire.Api và thêm các biến môi trường cần thiết tương tự trong file `.env.example`.
